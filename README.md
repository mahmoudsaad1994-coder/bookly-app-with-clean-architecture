Bookly App! 📚
I'm excited to present a sneak peek of the Bookly App—a project I developed to solidify my skills in Bloc and Cubit state management, along with the MVVM pattern in Flutter. 🚀
This app combines efficient state management with clean architecture, making it a joy to use. From browsing through a collection of books to managing your favorites, the Bookly App is designed to deliver a smooth and engaging user experience.
